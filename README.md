# Sports Motion Analysis

## Affiliations
CS Society (led by Seoha David Kim)
PE Society (led by Jianyuan Max Ma)

## Objective
An app that analyses one's body movements (in sports) using a camera to take input and processing it through a trained model to analyse body movements, outputting suggestions for improvement. The goal is to optimise the performance of athletes through personalized feedback based on their attributes and physical abilities.
